What is Suffice?

A desktop coding agent. You describe a feature, bug or refactor, and Suffice plans it, writes the code, runs it and tests it, choosing models along the way so you don't overpay.

Is it free?

Yes. The app is free with your own API key. Paid features will come later, and we'll announce pricing before anything changes.

Can I use my existing API keys?

Yes. Add a key from your provider and you're billed by them at their normal rates. Whatever Suffice saves shows up on your own bill.

Do I have to stop using Claude Code or Codex?

No. SNet, in beta, connects them to Suffice and to each other so they can share context and hand off work.

Where does my code go?

The agent runs on your computer. Code is only sent to the model provider you configure, under your key.

How was the 41% measured?

On our own run of SWE-bench Lite: 300 tasks, 5 attempts each, comparing Opus to Suffice (Golem). Average cost per task went from $0.27 to $0.16 with accuracy level. The full method is public.
